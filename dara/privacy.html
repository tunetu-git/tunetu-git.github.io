What the app is

“Dara Automat” is an internal tool used exclusively for DARA's own YouTube channel, Dara_Official. The app is not offered to the public. Only the owner of that channel signs in to it; no other users sign in or provide data.

Which Google user data the app uses

The app uses the YouTube API Services (YouTube Data API and YouTube Analytics API) with the permission that the channel owner grants once. With it, the app:

  • uploads DARA's own short videos to the Dara_Official channel,
  • sets the title, description, tags, category, language, audience and publishing time of the channel's videos,
  • edits the channel description and creates and fills the channel's playlists,
  • reads basic information and statistics of this one channel and its own videos (for example view counts, countries and traffic sources) to plan future posts.

The app does not read, collect or store data of any other YouTube or Google user, and it does not access messages, contacts, e-mail or files.

How the data is stored and protected

The only stored credential is the OAuth token (refresh token) for the Dara_Official channel. It is kept encrypted in a private code repository and used only by the automated jobs that manage the channel. Videos, texts and schedules are DARA's own content.

Sharing, selling, advertising, AI

Data obtained through Google APIs is not sold, not shared with third parties, not used for advertising and not used to develop, improve or train generalized artificial intelligence or machine learning models. The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

This app uses YouTube API Services. By using it, the channel owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Retention, revocation and deletion

The token is kept only as long as the tool is in use. Access can be revoked at any time on the Google account's security settings page. After revocation, or on request to the contact address above, the stored token is deleted.

This website

This website uses no cookies, no tracking and no analytics. It is hosted on GitHub Pages; GitHub may process technical access data such as IP addresses, as described in the GitHub Privacy Statement.

Your rights

You can request information about, correction of, or deletion of personal data concerning you, under the Swiss Federal Act on Data Protection and, where applicable, the GDPR. Write to the contact address above.
